
# 🎮 GameZone — Enter the Arena

Welcome to **GameZone**, a colorful and interactive gaming website inspired by online gaming platforms like Poki. Discover games, explore categories, save your favorites, and enjoy quick gaming challenges.

## ✨ Features

- 🎨 Modern, colorful, responsive design
- 🔍 Search games by name or category
- 🕹️ 36 game cards across multiple categories
- 🏎️ Categories include Racing, Puzzle, Arcade, Sports, Action, and Casual
- ❤️ Add games to your favorites
- 🎲 Random game selection
- ↕️ Sort games alphabetically or by popularity
- ➕ Load more games dynamically
- 🎯 Built-in 15-second target-tapping mini-game
- 🏆 Save your personal best score locally
- 📱 Responsive layout for desktops, tablets, and mobile devices
- ✨ Animated cards and interactive hover effects

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, animations, and responsive layout
- JavaScript — Search, filters, favorites, sorting, and mini-game logic
- LocalStorage — Saving favorites and the best score
- Google Fonts — Typography

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the games and try the built-in mini-game.

No installation or build tools are required.

## 🌐 Deploy with GitHub Pages

1. Upload all project files to your GitHub repository.
2. Open your repository on GitHub.
3. Go to **Settings → Pages**.
4. Under the build and deployment settings, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Wait for deployment and open the published website link shown in GitHub Pages.

## 🎮 About the Games

GameZone currently displays 36 game previews and includes a playable target-tapping mini-game.

The other game cards are demonstrations of the website's interface, not complete playable games. Additional games can be integrated using original HTML5 games or third-party games that explicitly allow embedding.
